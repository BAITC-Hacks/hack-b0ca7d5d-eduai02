# Определение дефекта по изображению

В этом проекте я сделала небольшой CLI-классификатор для учебной задачи по компьютерному зрению. Скрипт принимает путь к изображению и печатает один результат: `OK` или `DEFECT`. В репозитории есть два примера — `ok.png` и `defect.png`.

## Запуск

Понадобятся Python 3.10+ и библиотека Pillow. Из корня репозитория выполните:

```powershell
python -m pip install -r requirements.txt
python classify.py ok.png
python classify.py defect.png
```

Для своего изображения передайте путь к файлу: `python classify.py "C:\images\photo.png"`.

## Результат

| Файл | Вывод |
| --- | --- |
| `ok.png` | `OK` |
| `defect.png` | `DEFECT` |

## Как это работает

Скрипт переводит изображение в RGB и считает долю красных пикселей. Пиксель считается красным при `R ≥ 140`, `R − G ≥ 50` и `R − B ≥ 50`. Если доля таких пикселей составляет хотя бы 25%, выводится `DEFECT`; иначе — `OK`.

Это простая цветовая эвристика: результат на реальных фото зависит от освещения и фона. Тестовые изображения можно создать заново командой `python make_examples.py`.
