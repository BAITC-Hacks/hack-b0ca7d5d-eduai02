# Есть дефект или нет

Я сделала простую программу, которая определяет результат по цвету картинки. Если на ней много красного, программа выводит `DEFECT`. В остальных случаях выводит `OK`.

Для примера я добавила две картинки: зелёную `ok.png` и красную `defect.png`.

## Как запустить

Нужен Python 3.10 или новее и библиотека Pillow. В папке проекта выполните:

```powershell
python -m pip install -r requirements.txt
python classify.py ok.png
python classify.py defect.png
```

У меня получилось:

```text
ok.png     -> OK
defect.png -> DEFECT
```

Чтобы проверить другую картинку, передайте путь к ней:

```powershell
python classify.py "C:\путь\к\картинке.png"
```

Примеры можно создать заново командой `python make_examples.py`.

## Как работает программа

Я считаю пиксель красным, если красный цвет в нём достаточно яркий и заметно сильнее зелёного и синего. Если таких пикселей хотя бы 25% от всей картинки, результат — `DEFECT`. Это простое правило для задания, поэтому на настоящих фотографиях оно может ошибаться из-за цвета фона или освещения.
